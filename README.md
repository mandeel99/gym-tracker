# Gym Plan

Phone-friendly beginner gym tracker: Upper/Lower split + light full-body day, set checkboxes, a **⚖ Load** button that suggests what weight to put on (double progression), and a daily food/steps/weight checklist.

Live: https://mandeel99.github.io/gym-tracker/

Logs are stored in your browser only (localStorage). Use **Daily → Backup → Export** now and then.
